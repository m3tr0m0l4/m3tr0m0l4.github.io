proxy tips and limitations

this page is dedicated to logging some notable limitations and uses of the proxy. note that any links given, unless otherwise mentioned, should not be directly clicked, and instead should be accessed within the proxy

useful sites that are unblocked!

  • internet archive (archive.org) -- incredibly useful for finding books, webpage archives, movies; basically anything you can think of
  • social media -- not "useful" per se, but still impressive. instagram and tiktok are completely unblocked as far as I can tell, even using just scramjet (more on that later)
  • duckduckgo (type duckduckgo.com into the searchbar after launching scramjet) -- a fast, private, and secure search engine that works flawlessly on scramjet. google will hit you with annoying captchas ("click on all of the crosswalks") since it doesn't like you using a proxy. duckduckgo doesn't mind. use it

dealing with roadblocks / miscellaneous tips & tricks

  • tip #1: layer it! -- if you find that a page you are attempting to access is blocked by the website's host or other security measures (e.g. reddit, cloudflare-hosted sites), try opening a virtual browser within the proxy. these often have pretty disgusting input lag, so i wouldn't recommend this method for games, but it works ¯\_(ツ)_/¯
    example(s): browser.lol (reddit will work on here)
  • tip #2: remember your info. -- this applies to sites that need you to sign in before using them (most social media apps). it's not rocket science, just remember your login info
  • tip #3: don't be an idiot. -- do not start boasting about this as loud as you can in class. this proxy is not intended for dumb stuff, it is mainly a resource for accessing sites that really should be unblocked already (archive.org, forums) and secure browsing, not so you can go on the hub on your school computer. it is a tool. do not abuse it please
