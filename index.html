proxy tips and limitations

this page is for notable limitations and uses of the proxy. unless otherwise mentioned, any links listed here should be opened inside the proxy, not directly.

useful sites that are unblocked

  • internet archive (archive.org) -- useful for books, archived webpages, movies, and more.
  • social media -- instagram and tiktok seem to work through scramjet.
  • duckduckgo -- type duckduckgo.com into the search bar after launching scramjet. it works better than google, which often throws captchas.

dealing with roadblocks / tips

  • tip #1: layer it. if a site is still blocked, try opening a virtual browser inside the proxy. it can be laggy, but it sometimes works for sites like reddit.
  • tip #2: remember your info. if a site needs login, make sure you know your username and password.
  • tip #3: don't be an idiot. don't loudly advertise this in class. use it as a tool, not for dumb stuff.

if the proxy doesn't work at all, sorry. if it does, have fun.
